## Dual-screen ports for the AYN Thor

Classic PC games running natively on the AYN Thor, with the game on the top screen and a touch deck on the bottom screen. Free and open source, bring your own game files.

**Overview with videos and FAQ: [toravo.de/en/thor](https://toravo.de/en/thor/)** ([Deutsch](https://toravo.de/thor/))

| Port | Game | Bottom screen | Videos |

| [Thor RA2](https://github.com/harmssi/thor-ra2) | Red Alert 2 / Yuri's Revenge | command deck: build tabs, radar, superweapons, control groups, zoom | [Install](https://youtu.be/hMupGiEim60) · [Gameplay](https://youtu.be/DOWgL-C954M) |
